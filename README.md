# ToDo — список задач на React

Минималистичный менеджер задач: React 19 + Vite 8 + Tailwind CSS 4 + [shadcn/ui](https://ui.shadcn.com)
(пресет `radix-nova`: примитивы Radix, шрифт Geist, иконки lucide).
Всё хранится локально в браузере, бэкенд не нужен.

## Возможности

- добавление, редактирование (двойной клик или ✏️) и удаление задач;
- фильтры «Все / Активные / Готовые» со счётчиками и прогресс-баром;
- «Отметить все» и «Очистить выполненные» — с отменой действия в тосте sonner;
- тема light / dark / system через next-themes, без вспышки светлого фона при загрузке;
- сохранение в `localStorage` + синхронизация между вкладками;
- горячие клавиши: `/` или `Ctrl`/`⌘ + K` — фокус в поле ввода, `Enter` — сохранить, `Esc` — отмена;
- доступность: примитивы Radix, подписи для скринридеров, видимый фокус, поддержка `prefers-reduced-motion`.

## Запуск

```bash
npm install
npm run dev
```

Прочие команды: `npm run build`, `npm run preview`, `npm run lint`.

## Структура

```
src/
├── components/
│   ├── ui/       примитивы shadcn/ui — генерируются CLI, вручную не правим
│   └── *.jsx     логика приложения: ввод, список, элемент, переключатель темы
├── hooks/        useTodos (данные) и useLocalStorage (хранилище)
├── lib/          cn(), форматирование дат, список фильтров
└── index.css     токены темы shadcn (--background, --primary, --radius …)
```

Добавить новый примитив:

```bash
npx shadcn@latest add <component>
```

Данные старой версии (ключ `todos` формата `{ text, isComplete }`) автоматически переносятся
в новый формат `todo.items` при первом запуске.
