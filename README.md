# ToDo — список задач на React

Минималистичный менеджер задач: React 19 + Vite 8 + Tailwind CSS 4.
Всё хранится локально в браузере, бэкенд не нужен.

## Возможности

- добавление, редактирование (двойной клик или ✏️) и удаление задач;
- фильтры «Все / Активные / Готовые» со счётчиками и прогресс-баром;
- «Отметить все» и «Очистить выполненные» — с отменой действия (Undo);
- тема light / dark / system, без вспышки светлого фона при загрузке;
- сохранение в `localStorage` + синхронизация между вкладками;
- горячие клавиши: `/` или `Ctrl`/`⌘ + K` — фокус в поле ввода, `Enter` — сохранить, `Esc` — отмена;
- доступность: роли и подписи для скринридеров, видимый фокус, поддержка `prefers-reduced-motion`.

## Запуск

```bash
npm install
npm run dev
```

Прочие команды: `npm run build`, `npm run preview`, `npm run lint`.

## Структура

```
src/
├── components/   UI: ввод, список, элемент, фильтры, тема, тост отмены, иконки
├── hooks/        useTodos (данные), useLocalStorage (хранилище), useTheme (оформление)
├── lib/          вспомогательные функции (форматирование дат, список фильтров)
└── index.css     тема Tailwind 4: цвета, шрифты, анимации
```

Данные старой версии (ключ `todos` формата `{ text, isComplete }`) автоматически переносятся
в новый формат `todo.items` при первом запуске.
